## Overview & AGPL-3.0 Section 13 Compliance

This repository publishes the complete source overlay, authentication bridge, Nginx reverse-proxy configuration, and Cosmos-Void theme stylesheet applied to the multi-channel social scheduling interface hosted at **`https://social.fogarmy.com`**, in fulfillment of **GNU Affero General Public License v3.0 (AGPL-3.0) Section 13**:

- **Live Network Source Offer:** [https://social.fogarmy.com/_fas/open-source.html](https://social.fogarmy.com/_fas/open-source.html)
- **Upstream Base Project:** [gitroomhq/postiz-app](https://github.com/gitroomhq/postiz-app) (AGPL-3.0)
- **Architectural Boundary ("Mere Aggregation" under AGPL-3.0 Section 5):** All FogArmy billing (`Stripe Checkout`), omnichannel inbox triage (`inbox.fogarmy.com`, MIT), workflow automation (`hooks.fogarmy.com`, MIT), and shortlink attribution (`go.fogarmy.com`, MIT) operate as separate, decoupled services outside this repository.
